# homebrew-tap

Homebrew tap for [Archivist](https://github.com/ramtinJ95/archivist) and
[Macarchy](https://github.com/ramtinJ95/macarchy).

## Install

```bash
brew install ramtinJ95/tap/archivist
brew install ramtinJ95/tap/macarchy
```

## Upgrade

```bash
brew upgrade archivist
brew upgrade macarchy
```
